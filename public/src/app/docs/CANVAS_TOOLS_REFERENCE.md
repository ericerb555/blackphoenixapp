## 📍 LEFT SIDEBAR TOOLS (Main Drawing Tools)

### **1. Select Tool** (Move icon)
**Activation:** Click button or press `V`
**Function:** 
- Select individual elements
- Move selected elements
- Resize with handles
- Rotate elements
**Multi-Select:**
- Shift+Click for multiple
- Drag box to select area
- Lasso selection available

---

### **2. Wall Tool** (Pencil icon)
**Activation:** Click button or press `W`
**Function:**
- Draw walls
- Click to start, click to end
- Continuous mode (keep drawing)
- Snap to angle (0°, 45°, 90°)
- Snap to endpoints
**Properties:**
- Thickness: 6" default
- Height: 96" (8 feet) for 3D
- Color: Customizable
**Overlay Features:**
- Live length display
- Live angle display
- Toggle snap on/off
- Toggle continuous mode
- Finish/Cancel buttons

---

### **3. Door Tool** (DoorOpen icon)
**Activation:** Click button or press `D`
**Function:**
- Place doors
- Standard sizes (30", 32", 36")
- Swing direction
- Single/double options
**Placement:**
- Click to place
- Drag to orient
- Snap to walls

---

### **4. Window Tool** (SquareDashed icon)
**Activation:** Click button or press `N`
**Function:**
- Place windows
- Standard sizes
- Single/double hung
- Casement/awning options
**Placement:**
- Click to place
- Position on walls
- Height adjustable

---

### **5. Room Tool** (Square icon)
**Activation:** Click button or press `R`
**Function:**
- Define room boundaries

**Properties:**
- Width/Height

- Fill color

---

### **6. Measure Tool** (Ruler icon)

## 🎯 CANVAS OPERATIONS

### **Selection Operations**
- **Single Select:** Click element
- **Multi-Select:** Shift+Click
- **Box Select:** Drag empty area
- **Lasso Select:** Advanced tool
- **Select All:** Ctrl+A
- **Deselect:** Esc or click empty

### **Edit Operations**
- **Move:** Drag selected
- **Copy:** Ctrl+C
- **Paste:** Ctrl+V
- **Duplicate:** Alt+Drag
- **Delete:** Delete key
- **Undo:** Ctrl+Z
- **Redo:** Ctrl+Y

### **Transform Operations**
- **Rotate:** Rotation handle
- **Scale:** Corner handles
- **Resize:** Edge handles
- **Flip:** Context menu
- **Align:** Smart guides

### **Organization**
- **Group:** Ctrl+G
- **Ungroup:** Ctrl+Shift+G
- **Lock:** Right-click → Lock
- **Hide:** Layer panel
- **Layer:** Assign to layer
