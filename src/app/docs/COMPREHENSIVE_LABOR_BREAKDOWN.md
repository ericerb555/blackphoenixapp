## 💰 PRICING STRUCTURE

### **Each Labor Item Includes:**
```typescript
{
  id: string;              // Unique identifier
  task: string;            // Detailed task description
  skill: string;           // Trade/skill level required
  hours: number;           // Estimated hours
  rate: number;            // Hourly rate ($45-$150)
  total: number;           // Calculated total (hours × rate)
  markup: number;          // Individual item markup %
  category: string;        // Task category
  phase: string;           // Construction phase
}
```

## 🔧 KEY FEATURES

### **✅ Dual Markup System**
- **Individual Item Markup**: Set custom markup per task
- **Section Markup**: Apply overall markup to labor section
- **Compounding**: Individual markups apply first, then section markup

### **✅ Categorization**
- Organized by construction phase
- Grouped by trade/category
- Easy filtering and sorting
- Professional presentation

### **✅ Visibility Controls**
- Show/hide individual tasks from customer
- All tasks still calculated in total
- Protect pricing strategy
- Streamlined customer presentation

### **✅ Helper Functions**
```typescript
getLaborItemsByPhase(phase: string)      // Filter by phase
getLaborItemsByCategory(category: string) // Filter by category
getAllPhases()                            // Get unique phases
getAllCategories()                        // Get unique categories
calculatePhaseTotal(phase: string)        // Sum by phase
calculateCategoryTotal(category: string)  // Sum by category
```
