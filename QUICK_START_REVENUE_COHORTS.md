## 💡 Understanding Your Data

### MRR (Monthly Recurring Revenue)
```
MRR = Sum of all active monthly subscription revenues
Example: 
  - Basic Build: 50 subscribers × $999 = $49,950
  - Pro Build: 30 subscribers × $2,199 = $65,970
  - Enterprise Build: 10 subscribers × $3,999 = $39,990
  Total MRR = $155,910
```

### ARR (Annual Recurring Revenue)
```
ARR = MRR × 12
Using example above: $155,910 × 12 = $1,870,920 ARR
```

### Growth Rate
```
Growth Rate = Average monthly subscriber growth across all cohorts
Helps project future revenue
```

### Category Revenue
```
Shows how much revenue each business segment generates:
- Construction subscriptions
- Customer subscriptions  
- Vendor partnerships
- etc.
```

## 🔄 How Revenue Updates

### Automatic Updates
- Revenue Hub refreshes data every **60 seconds**
- No manual action needed
- Always shows latest subscriber counts and revenue

### Manual Refresh
- Click "Refresh Data" button anytime
- Forces immediate data pull from backend
- Useful after making changes in Advanced Cohort Manager

### When Subscribers Change
1. User subscribes to a plan (e.g., Pro Build $2,199/mo)
2. Backend automatically updates subscriber count
3. Revenue recalculated (subscribers × price)
4. Revenue Hub shows updated MRR within 60 seconds

## 🛠️ Troubleshooting

### "No cohort data available"
**Solution:** Click "Initialize System" to populate default cohorts

### "Failed to load revenue data"
**Solution:** Check server connection, click "Refresh Data" button

### Revenue shows $0
**Solution:** 
1. Click "Initialize System" to create sample data
2. OR add subscribers to existing cohorts
3. Revenue = subscribers × price (need both)

### Numbers don't match expectations
**Solution:**
1. Click "Refresh Data" to get latest
2. Check Advanced Cohort Manager for subscriber counts
3. Verify pricing in cohort settings
